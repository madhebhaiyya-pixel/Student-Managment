# Student Grade Management System

A console-based Java application developed as part of the CodeAlpha Java Programming Internship.

## Features
- Accepts student names and marks as input.
- Stores student records using ArrayList.
- Calculates the average marks of students.
- Finds the highest and lowest scores.
- Displays a summary report of all students.
- Validates marks between 0 and 100.

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse IDE.
3. Run `StudentGradeManagement.java`.
4. Enter the number of students, their names, and marks.
5. View the student summary report in the console.

## Purpose
This project demonstrates basic Java programming, collections, loops, conditional statements, and student grade management.
